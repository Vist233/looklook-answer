# 看题 · Page Vision

无需构建的 Chrome 扩展：截取当前标签页可见区域，通过你配置的图片模型 API，流式解答当前正在作答的一道题。

当前版本 **1.7.0**。支持 OpenAI 兼容和 Anthropic 兼容接口、独立 Thinking 区域、四类题型格式及本地答案历史。

## 安装与更新

1. 在 [GitHub 仓库](https://github.com/Vist233/looklook-answer) 点击 **Code → Download ZIP**，下载后解压；也可使用 Git 克隆。
2. Chrome 打开 `chrome://extensions`，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的项目目录。
4. 将“看题 · Page Vision”固定到工具栏。

不需要安装 Node、Python 或运行构建命令。Node 只用于开发测试。

更新时替换文件，在扩展管理页点击重新加载，再刷新原网页并重新开启。仅修改文件不会更新已经注入网页的旧脚本。现有配置和历史会保留；卸载或清除扩展数据可能移除它们。

## 配置 API

打开普通网页，点击扩展图标，填写并保存 API URL、Model Name 和 API Key。模型必须支持图片输入；接口兼容不保证所选模型支持图片。

| 协议 | API URL | Model Name |
| --- | --- | --- |
| OpenAI 兼容 | `https://api.xiaomimimo.com/v1` | `mimo-v2.6-pro` |
| Anthropic 兼容 | `https://api.xiaomimimo.com/anthropic` | `mimo-v2.6-pro` |

也可填写完整 `/chat/completions` 或 `/messages` 地址。项目不附带密钥，使用者自行申请和填写。

MiMo 主机下模型名末尾 `[1m]` 会被代码移除；请直接填写供应商认可的模型 ID。该转换不表示已启用或验证百万 token 上下文。

MiMo 请求开启思考，不发送未公开的 `reasoning_effort`。Anthropic 使用 `budget_tokens: 1024`，不等价于 `effort: low`。能力、费用和参数支持取决于供应商。细节见 [开发说明](docs/DEVELOPMENT.md)。

## 怎么使用

1. 将当前题目及必要图片放入浏览器可见区域。
2. 开启“自动分析”。浏览器会询问网页访问权限，用于在当前标签页跨网站导航后继续工作。
3. 开启时立即截图分析。把分析框拖到不遮挡题目的位置。
4. 后续点击网页或 URL 改变，等待 **1.6 秒**再截图请求；再次触发会重新计时。
5. 查看 Thinking 和答案。“复制”仅复制答案，“历史”可查看和导出记录。
6. 需要立即刷新答案时点击“重新分析”；结束后关闭开关或分析框。

### 哪些操作触发请求

| 操作 | 行为 |
| --- | --- |
| 开启、重新分析、运行时保存配置 | 立即开始 |
| 点击网页，包括选项、空白处及辅助点击 | 等待 1.6 秒；连续点击重置 |
| 同页 URL 路由改变 | 等待 1.6 秒 |
| 整页导航或刷新 | 加载完成后等待 1.6 秒 |
| 扩展框内点击、脚本合成点击 | 不自动触发 |
| 鼠标移动、悬停、滚动、键盘输入 | 不自动触发 |
| 视频、动画、后台 DOM 更新、切回标签页 | 不自动触发 |

目前没有“同题去重”：点击选项也可能重新请求。单纯滚动到新题或网页自动换题但 URL 不变时，请使用“重新分析”。本版本不监听 DOM 变化，也不轮询截图。

新请求会取消旧请求，无论旧请求处于连接、Thinking 还是输出阶段；仅最新请求更新界面。切换到其他标签页时取消进行中的请求，切回不会自动重试。

## 当前题目与输出格式

1.7.0 提示词仅解答当前一道题，依据截图中的当前题号、选中题号或题目区域定位。多道题同时出现且无法定位时，只说明无法确定当前题目。当前定位由图片模型完成，尚无 DOM 题目提取。

- 判断题：正确（√）或错误（×），附一句依据。
- 单选题：一个字母及选项原文，附一句依据。
- 多选题：按字母顺序列出答案及所选原文，附一句依据。
- 简答题：完整作答，多个要点分行编号。

看不清或信息不足时说明原因，不猜测。提示词不能保证模型一定遵循或答案一定正确。完整提示词在 `core.mjs` 的 `SYSTEM_PROMPT` 和 `IMAGE_PROMPT` 中。

Thinking 区域展示 API 实际返回的思考文本，可折叠。供应商没有返回该字段时只能显示阶段状态；扩展不会补造内容。

## 本地历史、数据与权限

最近 100 条答案存储于 Chrome 扩展本地，约 4 MiB 上限。包含时间、页面标题/URL、模型、答案、状态及耗时，支持查看、导出 JSON 和清空。取消后已有部分答案的请求也可能记录。

- API Key 存在扩展本地，不同步、不写入源码；这不是加密保险库。可在弹窗清除密钥。
- 截图仅在运行时处理，发送到配置的 API，不存入历史。
- Thinking 不保存到历史，不进入答案复制结果。
- 开启请求 HTTP(S) 网页访问权限，但分析范围只有开启的标签页。
- 20 秒心跳不截图、不读取题目、不调用模型。
- 请求可能产生费用；取消客户端请求不保证供应商停止计算或免收费用。

公开分享历史前，检查其中的页面标题、URL 和答案。仓库应只含源码、文档及测试，不应含密钥或个人历史。

## 常见问题与限制

**修改后没生效？** 重新加载扩展、刷新网页，确认版本为 1.7.0。

**页面不动却重新请求？** 每次真实网页点击均触发，包括选择答案；尚无题目身份判断。鼠标移动本身没有监听。

**滚动后没有分析？** 滚动不触发，请点击“重新分析”。

**没有 Thinking 内容？** 模型需开启思考，且 API 返回 `reasoning_content` 或 Anthropic thinking 事件。阶段状态不等于服务端已返回思考正文。

**连接后很久没输出？** 查看当前阶段及错误。请求超时上限 120 秒；界面显示本地准备、答案首字及 API 总耗时，不能把全部等待都归因于模型计算。

只截图可见区域，不自动滚动、填选项或提交。灰色遮挡位置无法恢复下面的内容。普通 HTTP(S) 页面可用，浏览器内部页面不可用；无访问权限的 iframe 点击无法监听。分析框会修改页面 DOM，不提供隐身或反检测功能。
